③ 两条线为什么差这么多：A / B / C 仓位隔离

B = 只做多；C = 空头信号仍占住仓位、但不开空单；A = 完整多空双侧。 中信从 1.016 → 2.525 的 1.509 点，可以拆成「空单自己赚的」+「空单占仓位挡掉的多单」。
柱高 = 累计点数；B / C / A 三组自左至右。

④ 证伪：两条策略各自的主判据

零假设必须保持原来的执行结构（信号成簇、单仓位不叠加、同样密度），否则会把「执行纪律」的功劳错记成「席位的预测力」。灰柱 = 随机分布，红线 = 真实值。
