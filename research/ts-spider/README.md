# TS 国债期货「蜘蛛网」策略复现

参考国泰海通《债市量化系列之五：国债期货多空持仓因子择时的再优化，引入"蜘蛛网"策略》
(2025-05-30)，用中金所 **TS（2 年期国债期货）会员持仓**复现静态版择时策略，
并做与报告差异的定量归因。

> 本目录是研究与代码快照，不构成投资建议。数据来自 Wind 导出，仅供个人研究使用。
> 已同步到公开仓库 `Ericshunjian/ficc-dashboard` 的 `research/ts-spider/` 子目录，

## 一、另一台电脑怎么用

所有脚本都用 `os.path.dirname(os.path.abspath(__file__))` 定位目录，
**整个文件夹放到任意位置都能跑，不需要改任何路径**。

1. 装依赖（Python 3.10+）：

   ```
   pip install pandas numpy openpyxl
   ```

2. **只想看结果**：在线打开 <https://ericshunjian.github.io/ficc-dashboard/research/ts-spider/>；
   或 `git clone https://github.com/Ericshunjian/ficc-dashboard.git` 后进入 `research/ts-spider/`，
   双击两个 HTML（单文件、数据已内嵌、离线可开，不用起服务器）。

   - `TS_蜘蛛网_持仓整理.html` — 持仓量 / dB·dS 信号 / **各信号净值对比** / 多空分解 / 质检
   - `TS_蜘蛛网_策略回测.html` — 净值·回撤 / **全部序列净值对比** / 与报告对照 / 零假设 / 成本 / 逐笔明细

3. **要重跑**（补了新数据或改了脚本），按下面顺序执行：

   ```
   python build_spider_web.py          # ① 读 45 个源 Excel → 整理 Excel / JSON / 持仓整理网页
   python spider_backtest.py           # ② 读整理 JSON + TS.CFE.xlsx → 回测 JSON / Excel / 回测网页
   python build_spider_web.py          # ③ 再跑一次①，把②生成的净值数据内嵌进整理网页
   ```

   ★ 顺序不能乱：整理网页的「各信号净值图」取自 `TS_策略回测.json`。
   仓库已带全部产物，所以**第一次只跑①也能显示净值图**（用的是仓库里的回测快照）；
   只有改了源数据 / 回测规则，才需要 ②→③ 刷新。

4. **可选诊断**：`python spider_rule_leverage_diag.py` → `TS_规则杠杆归因.json`
   （12 种开平仓变体、9 档杠杆、Oracle 上限、2020 缺口外推）。

5. **补数据**：把 Wind 导出的 `会员：XXX 品种：TS 2年期国债期货.xlsx`
   放进对应年份文件夹，再按上面顺序重跑。年份文件夹名支持 `2021年` ~ `2026年（截至11月23日）`。

## 三、数据口径（改动前务必先读）

- Wind 导出的**空单量带负号**，先取绝对值再计算；源表 `净持仓 = 多单量 + 空单量`（恒等，零误差）。
- `dB` = 多单量日变动；`dS` = 空单量（绝对值）日变动，`dS>0` 表示空头增加。
- 信号（报告第 79 行）：`dB>0 且 dS<0 → 做多(+1)`；`dB<0 且 dS>0 → 做空(-1)`；其余 0。
- 开平仓（报告第 85 行）：T 日仓位为 0 → **T+1 开盘全仓建仓、T+2 收盘平仓**；
  T 日仓位与信号反向 → T+1 开盘平仓。单倍杠杆、初始 1000 万、零成本（报告未写成本）。
- **净值口径（2026-11-24 改）**：固定 5 手 TS（面值 200 万/手、报价按 100 元面值
  ⇒ 1 点 = 2 万元/手 = 10 万元/组 = 初始资金 1000 万的 1%），名义敞口恒定、单倍杠杆。
  逐笔盈亏 = 方向 × (平仓价 − 开仓价) **点**，**净值 = 1 + Σ(点数/100) 直接累加、不复利**。
  原实现用「Δ价 / 开仓价」当收益率再 `(1+r)` 累乘，隐含"每期按当前净值比例重新定仓"，
  与固定手数不符，且分母随开仓价浮动；现已全链路统一（含基准、零假设、杠杆诊断、两个网页）。
  年化按单利 = 累计收益 × 243 / 交易日数。口径修正只让累计收益从 1.245% → 1.307%，不改变结论。
- 跨年按**连续交易日** diff，不在每年首日断开；相邻任一端缺失则该日留空、不跨越。
- 空单量 NaN = 会员当日未进空单前 20 榜，按 0 处理（此时源表净持仓恰等于多单量，自洽）。
- 国泰海通（合成）= 国泰君安 + 海通期货逐日相加；缺任一腿则该日留空。
- 持仓表结算价与 `TS.CFE` 收盘价**水平差约 2.9 点**（不同连续合约口径），
  但日变化相关 0.84、差值标准差 0.027 点；回测执行价统一用 `TS.CFE` 开/收盘。

## 四、当前结论（截至 2026-11-24，样本 2021-01-04 ~ 2026-11-23，1426 交易日）

- **前 20 大合计（报告静态版）**：累计 1.307%（= 1.307 点）、年化 0.22%、夏普 0.67、最大回撤 0.50%、183 笔。
  报告公布 9.52% / 1.84% / 0.83 / 1.02%，**本地无法复现**；报告可比段本地仅 0.727% / 0.46 / 131 笔。
- 差异不是成本、不是杠杆、不是开平仓规则：
  - 报告第 3 页明写「杠杆倍数为单倍杠杆」；反推需 7.3~13.1 倍才能凑到 9.52%，
    但回撤会同步放大、夏普不变，且报告回撤仅 1.02%。
  - 12 种开平仓 / 信号时点变体全部落在 −1.31% ~ +1.31%（可比段 −0.73% ~ +0.90%），没有一个接近 9.52%。
  - Oracle 上限（方向 100% 全对、零成本）在报告区间仅 7.997%，**报告值还比它高 19%**。
  - 报告净值 5 年平滑近线性、未披露价格序列 / 交易笔数 / 净值算法（是否复利），应先当待证伪对象。
- 零假设对照（信号整体循环移位 200 次，`seed=20261123`）：
  - 前 20 大合计 p(累计)≈0.080 / p(夏普)≈0.065 **未过显著性**；符号翻转完全对称，无多头偏置。
  - 平安期货 p≈0.005 通过，但属看过示意结果后挑的序列，有数据窥探成分
    （Bonferroni 阈值 0.0125 下勉强过），循环移位也打乱了信号与波动率时序的对应，p 偏乐观。
- 成本一加即衰减：每笔来回仅扣 0.005 点（TS 一个最小变动价位），累计收益大幅缩水。
- **定位：刻度 + 证伪，不能上仓**。

## 五、已知数据缺口

| 缺口 | 影响 |
|---|---|
| 2020 年持仓缺 | 报告回测从 2020-01-01 起，本地可比段只能从 2021-01-04 起；外推补上后估计累计仍仅约 1.21% |
| 2026 海通期货源表缺 | 国泰海通（合成）2026 全段留空，末日停 2025-12-31 |
| 2021、2022 华泰期货源表缺 | 该序列有效日仅 940 天；净值在末次有效日后走平 |
| 2026-11-23 | 前5/前10 合计行仅结算价、持仓未刷新；单会员席位整体只到 11-20 |
| 源表缺 3 个交易日 | 海通 2025-11-27、2025-12-05，平安 2024-04-29（会员当日未进榜） |
| n=1~20 逐档合计缺 | 报告动态调参版无法复现，目前只能做静态版 |

另：2026 目录里的「国泰君安」是否已是合并后的国泰海通实体**未能从数据确认**
（2025 末 6297 → 2026 初 5730 连续，看不到并表应有的 +27% 跳增）。
静态版用前 20 家整体合计，不受单席位口径影响；做单会员 / 聪明资金筛选前需先拍板。
