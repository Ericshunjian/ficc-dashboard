## 三、数据口径（改动前务必先读）

- Wind 导出的**空单量带负号**，先取绝对值再计算；源表 `净持仓 = 多单量 + 空单量`（恒等，零误差）。
- `dB` = 多单量日变动；`dS` = 空单量（绝对值）日变动，`dS>0` 表示空头增加。
- 信号（报告第 79 行）：`dB>0 且 dS<0 → 做多(+1)`；`dB<0 且 dS>0 → 做空(-1)`；其余 0。
- 开平仓（报告第 85 行）：T 日仓位为 0 → **T+1 开盘全仓建仓、T+2 收盘平仓**；
  T 日仓位与信号反向 → T+1 开盘平仓。单倍杠杆、初始 1000 万、零成本（报告未写成本）。
- **净值口径（2026-11-24 改）**：固定 5 手 TS（面值 200 万/手、报价按 100 元面值
  ⇒ 1 点 = 2 万元/手 = 10 万元/组 = 初始资金 1000 万的 1%），名义敞口恒定、单倍杠杆。
  逐笔盈亏 = 方向 × (平仓价 − 开仓价) **点**，**净值 = 1 + Σ(点数/100) 直接累加、不复利**。
  原实现用「Δ价 / 开仓价」当收益率再 `(1+r)` 累乘，隐含"每期按当前净值比例重新定仓"，
  与固定手数不符，且分母随开仓价浮动；现已全链路统一（含基准、零假设、杠杆诊断、两个网页）。
  年化按单利 = 累计收益 × 243 / 交易日数。口径修正只让累计收益从 1.245% → 1.307%，不改变结论。
- 跨年按**连续交易日** diff，不在每年首日断开；相邻任一端缺失则该日留空、不跨越。
- 空单量 NaN = 会员当日未进空单前 20 榜，按 0 处理（此时源表净持仓恰等于多单量，自洽）。
- 国泰海通（合成）= 国泰君安 + 海通期货逐日相加；缺任一腿则该日留空。
- 持仓表结算价与 `TS.CFE` 收盘价**水平差约 2.9 点**（不同连续合约口径），
  但日变化相关 0.84、差值标准差 0.027 点；回测执行价统一用 `TS.CFE` 开/收盘。

## 四、当前结论（截至 2026-11-24，样本 2021-01-04 ~ 2026-11-23，1426 交易日）

- **前 20 大合计（报告静态版）**：累计 1.307%（= 1.307 点）、年化 0.22%、夏普 0.67、最大回撤 0.50%、183 笔。
  报告公布 9.52% / 1.84% / 0.83 / 1.02%，**本地无法复现**；报告可比段本地仅 0.727% / 0.46 / 131 笔。
- 差异不是成本、不是杠杆、不是开平仓规则：
  - 报告第 3 页明写「杠杆倍数为单倍杠杆」；反推需 7.3~13.1 倍才能凑到 9.52%，
    但回撤会同步放大、夏普不变，且报告回撤仅 1.02%。
  - 12 种开平仓 / 信号时点变体全部落在 −1.31% ~ +1.31%（可比段 −0.73% ~ +0.90%），没有一个接近 9.52%。
  - Oracle 上限（方向 100% 全对、零成本）在报告区间仅 7.997%，**报告值还比它高 19%**。
  - 报告净值 5 年平滑近线性、未披露价格序列 / 交易笔数 / 净值算法（是否复利），应先当待证伪对象。
- 零假设对照（信号整体循环移位 200 次，`seed=20261123`）：
  - 前 20 大合计 p(累计)≈0.080 / p(夏普)≈0.065 **未过显著性**；符号翻转完全对称，无多头偏置。
  - 平安期货 p≈0.005 通过，但属看过示意结果后挑的序列，有数据窥探成分
    （Bonferroni 阈值 0.0125 下勉强过），循环移位也打乱了信号与波动率时序的对应，p 偏乐观。
- 成本一加即衰减：每笔来回仅扣 0.005 点（TS 一个最小变动价位），累计收益大幅缩水。
- **定位：刻度 + 证伪，不能上仓**。

## 七、平安期货「逆势加多」主观感受检验（2026-11-24）

用户假设：价跌时平安净多增加 → 随后几个交易日涨；价涨时净多下降 → 随后跌。要求给出「加仓力度到多少跟开、持有几天」。

- **事前锁定口径**：力度 = 净持仓日变动 `dNet` 在过去 60 个交易日的百分位（含当日、只用历史，无前视）；T 日盘后信号 → T+1 开盘建仓 → T+1+H 收盘平仓；持仓期间不叠加；固定 5 手 TS、名义 1000 万、单倍杠杆；净值 = 1 + Σ(方向×Δ价 − 成本)/100，点数累加不复利。
- **口述规则（主口径，不参与任何调参）**：当日收跌且 dNet 分位 ≥ 80%（近 250 日约 **+571 手**）→ 次日开盘做多；收涨且 ≤ 20%（约 **−466 手**）→ 做空；持有 **3 个交易日**。
  全样本 **1.112 点 / 1.112%**、164 笔、夏普 0.45、逐笔 t=1.10；探索段 0.506 点 / 验证段 0.606 点。做多 85 笔 **+1.724 点**、做空 79 笔 **−0.612 点**。
- **证伪结果（这才是结论）**：
  - 「平安确实逆势」成立：dNet 与当日涨跌相关 **−0.158**；但「价涨+净多减」未来 3 日 −0.003 点 / t=−0.71，**第②半不成立**；反例「价跌+净多减」「价涨+净多增」也都涨。
  - 同一参数下归因：去掉平安只看价跌反弹 **1.639 点 > 完整规则 1.112 点**；价跌内部「大幅加多」比「力度不足」只多 0.0055 点、**Welch t=0.68** ⇒ 平安没有增量。
  - 同规则套到其他 8 席位全部为正，中信期货 **2.525 点**比平安还高 ⇒ 赚的是 TS 慢牛里「逢跌做多」的钱，不是平安独有信息。
  - 400 次循环移位零假设：整条信号 p=0.213、**只打乱平安力度 p=0.338**、验证段 p=0.258 ⇒ 均未过显著性。
  - 每笔平均仅 0.0068 点（约 1.4 个最小变动价位）；扣 0.005 点来回后累计 1.112 → **0.292 点**（−74%），0.01 点直接转负。
  - 探索段网格最优（`dB` / 不加价格条件 / H=1）全样本 3.076 点，但验证段只剩 0.604 点、逐笔 t 0.73；两段参数相关仅 0.21，walk-forward 参数逐年从 H=1 漂到 H=10 ⇒ **调参结果不可下注**。
- **定位：刻度 + 证伪，不能上仓。** C / E / G 对照组是证伪工具，不是「找到的更好策略」——它们本质是买 TS 慢牛的 beta。
- **★ 数据窥探警告**：平安是看过全样本净值（3.70%、夏普 1.18）之后才被挑中的序列，本身带选择偏差；样本外切分只能防参数过拟合，**防不了「挑序列」**。上面的横截面安慰剂与零假设就是为这个做的。

## 八、平安期货「只做多」策略（2026-11-24，承接第七节）

用户新要求：基于平安的逆势加多操作，**不做空，只择机做多**。参数完全沿用第七节口述规则，只关掉做空腿。

- **规则（事前锁定，未重新调参）**：当日收跌 且 `dNet` 60 日分位 ≥ 80%（近 250 日约 **+571 手**）→ T+1 开盘买 5 手 TS → 持有 **3 个交易日** → T+4 收盘平仓；单仓位不叠加；固定名义 1000 万、点数累加不复利。
- **绩效**：全样本 **3.096 点 / 3.096%**、**113 笔**（162 个信号日）、夏普 **1.43**、胜率 66.4%、逐笔 t=3.62、最大回撤 0.29%；探索段 1.431 点 / **验证段 1.665 点（夏普 1.65）**，样本外不衰减；6 个年份全为正。
